# Phase 1 · 快速验证（Quickstart）

> 面向「实现完成后怎么在本地证明它真的能用」。命令一律从仓库根执行；环境变量规则见 `docs/architecture/13-本地开发与命令.md`。
> **不需要 Vercel Blob 令牌也能完整验证**：本地默认走文件系统媒体驱动（`.data/media`），只有要验证生产路径时才配 `BLOB_READ_WRITE_TOKEN`。

## 1. 前置

```bash
pnpm install                      # 安装本期新增依赖（6 个 TipTap 包 + @vercel/blob）
pnpm db:setup                     # 建库、跑迁移、灌种子数据（本期无新迁移，行为不变）
pnpm dev                          # http://localhost:3000
```

可选（仅验证 Blob 生产路径）：在 `.env` 里加 `BLOB_READ_WRITE_TOKEN=…`（注意是 `.env`，不是 `.env.local`，见 AGENTS.md §5.3 的陷阱说明）。判定只看这一个变量，加了就 `mediaMode = 'blob'`，然后跑 `pnpm exec vitest run --config vitest.integration.config.ts tests/integration/media-blob.test.ts` 对真实私有桶做一次写入→代理读取→删除的往返；不加则一直是 `fs`。

## 2. 静态门（提交前必须全绿）

```bash
pnpm check && pnpm typecheck && pnpm test
pnpm arch:check          # 新文件 ≤400 行、只在 lib/config.ts 读 process.env
pnpm docs:check --strict # 新增 ADR 与架构文档改动
```

## 3. 手工验证路径（按用户故事）

### US1 · 建一篇谱文并写下第一段文字（P1）

1. 登录 → 进入任一云谱空间 → 左侧「谱文」。
   **期望**：列表页显示分类树（含「默认分类」与「未分类」）与谱文列表，空项目显示空态引导，不再出现「功能尚未开放」。
2. 点「新建谱文」→ 输入标题「重修族谱序」→ 创建。
   **期望**：直接进入编辑器，中区是一页空白页且光标可打字；左树里「默认分类」篇数 +1。
3. 输入两段文字，停止输入 2 秒。
   **期望**：顶栏状态由「保存中」变为「已保存 · HH:mm」；刷新页面后文字仍在。
4. 清空标题后失焦。
   **期望**：就近提示「标题不能为空」，保存被阻断，标题不会静默变回旧值。
5. 顶栏改标题为「重修族谱序（二修）」→ 回到列表。
   **期望**：列表显示新标题且排在最前；在搜索框输入「二修」能命中（P1）。
6. 在列表行内菜单（或编辑器顶栏）选「移到分类」→ 选另一个分类。
   **期望**：原分类篇数 −1、新分类篇数 +1，刷新后不变。
7. 删除一个仍有子分类的分类。
   **期望**：确认框写明「将同时删除 N 个分类，其中 M 篇谱文转为未分类」（计数来自 `getFolderDeletePreview`）；确认后子分类一并消失，谱文出现在「未分类」。
8. 查看编辑器顶栏与新建弹窗的「地区」。
   **期望**：显示云谱空间设置里的地区；云谱空间没设置时显示「中国」；该字段**只读**，无法编辑。
9. 用 `editor` 账号打开同一云谱空间。
   **期望**：能新建谱文、能选既有分类与「未分类」，但**看不到**「新建/重命名/删除分类」入口（分类写权限仍是 `project.write`，见 contracts §4）。

### US2 · 写长了就加页（P1）

1. 编辑器右栏点「+添加页」。
   **期望**：新增一页并自动切到该页，缩略图列表出现第 2 页。
2. 在第 2 页输入文字 → 点第 1 页缩略图。
   **期望**：切页前有改动的页先提交（顶栏短暂「保存中」），切换后两页内容各自正确，页面不刷新、不跳转。
3. 拖拽第 2 页到第 1 页之前。
   **期望**：页序立即改变并保存；刷新后页序保持。
4. 删除其中一页；再尝试删除最后一页。
   **期望**：第一次成功且页序连续；最后一页时提示「至少要保留一页」并拒绝。
5. 有未保存改动时点「返回」回列表。
   **期望**：先保存再导航；若保存失败则停留在编辑器并提示重试。
6. 有未保存改动时直接关闭标签页或刷新。
   **期望**：浏览器弹出原生「确定离开？」确认（`beforeunload`）；确认离开后重新打开，内容停在最后一次成功保存的状态。

### US3 · 配一张老照片（P1）

1. 在正文中把光标放到段落之间 → 点工具栏「插入图片」→ 选一张 JPG。
   **期望**：图片以块级独占一行插入，等比缩放不拉伸；默认「整宽」；顶栏出现保存状态并最终「已保存」。
2. 点图片 → 选「中」。
   **期望**：宽度变为中档并保存；刷新后仍为中档。
3. 选一个 20MB 的文件。
   **期望**：客户端先拦下并提示「只支持 JPG / PNG / WebP，单张不超过 10MB」，已有文字与图片**零变化**；绕过前端直接调上传接口同样被服务端拒绝（令牌不签发）。
4. 同一页已有 6 张图片时再插入第 7 张。
   **期望**：客户端给出「每页最多 6 张图片」；绕过前端伪造保存请求时服务端仍拒绝（服务端权威校验，契约见 contracts §1.5）。
5. 从别的网页复制一段带格式的文字 + 一张图，粘贴进正文。
   **期望**：只保留段落/标题与文字；外链图片被丢弃或提示；不出现彩色、加粗、表格、项目符号。
6. 删除含图片的那一页。
   **期望**：页被删除；`.data/media/articles/<orgId>/<articleId>/` 下该页独有文件消失（blob 模式下对应 pathname 被删除，日志可查）。

### US4 · 最后调一下字体（P2，可延后）

1. 选中一段文字 → 工具栏选「楷体」、字号「大」。
   **期望**：仅该段显示变化，保存后刷新仍生效。
2. 把这段文字复制到另一段。
   **期望**：字体与字号随文字带过去。
3. 在一台没有安装楷体的机器（或用系统字体替代的环境）打开。
   **期望**：显示为可用替代字体，不出现方块乱码。

> 自动化覆盖情况：第 1、3 项已由 `tests/e2e/article-authoring.spec.ts` 的 font 用例验证（本机未装楷体，`font-family: KaiTi` 仍生效且无控制台报错，即「替代字体而非方块」成立）；
> 第 2 项的 inline style 产出由 `tests/article-text-style.test.ts` 锁住，粘到外部富文本编辑器的实际效果仍需人工看一眼。

### 权限与越权（FR-033–FR-036）

1. 用 `viewer` 账号打开同一篇谱文。
   **期望**：可读，没有任何写入按钮/工具栏；直接构造保存请求也会被服务端拒绝（`forbidden`）。
2. 用另一个组织的账号猜 `articleId` 直接访问编辑器 URL。
   **期望**：404（按「不存在」处理），不泄露是否存在。
3. 用另一个组织的账号直接请求 `/api/media/articles/<他人orgId>/<articleId>/<file>`。
   **期望**：404（读取代理按 `orgId` 校验成员，不泄露存在性）。

### 删除与引用完整性（FR-004、FR-038）

1. 在谱书里把这篇谱文加进编目，再回谱文列表删除它。
   **期望**：提示「这篇谱文被谱书编目引用，请先在谱书里移除编目」并拒绝。
2. 移除编目后再删除。
   **期望**：确认框写明页数与图片数（来自 `getArticleDeletePreview`）；确认后列表不再出现该谱文。

## 4. 自动化验证

```bash
pnpm test:integration    # 需要 *_test 结尾的库；覆盖权限、FOR UPDATE 保存、页序、引用阻止、跨组织、媒体读取鉴权
```

## 5. 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 图片上传 401 / 404 | 会话过期或未登录；上传令牌与图片读取都要求会话 + 组织成员 |
| 图片显示裂图 | fs 模式下 `.data/media` 被清空，或 blob 模式下 pathname 不存在 → 检查文件/日志；读取 URL 每次都是新的，不需要「刷新签名」 |
| `pnpm test` 报「依赖 X 违反 ADR 0010「决策 ≠ 现在安装」」 | 删 ADR 0010 的「尚未安装」状态句时**连 `决策 ≠ 现在安装` 字面串一起删了**；该串必须保留（黑名单断言靠它跳过） |
| `pnpm arch:check` 报文件超 400 行 | 编辑器逻辑按 `components/article/editor/**` 拆分，不要堆在单文件 |
| 保存后刷新内容丢失 | 检查是否只改了本地状态没提交；服务端以 `article.content` 为准 |
| 保存成功但编辑器内容被「回退」 | 检查是否在保存路径上调了 revalidate（应当只在新建/改标题/移分类/删除时刷新列表） |

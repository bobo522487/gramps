- [x] 需求正文无实现细节：需求（FR）与成功标准（SC）不出现技术栈、目录结构、数据库列名、接口签名、依赖包名；Assumptions 的「已交付基线」「待确认」两表允许引用仓库现状与既有文档，仅用于记账，不构成实现方案

## Requirement Completeness

- [x] 无 `[NEEDS CLARIFICATION]` 残留：12 条 specify 阶段默认裁决（其中 2 条已随重定范围作废）+ 5 条 clarify 轮人工确认 + 1 条重定范围指令，均写入 Clarifications；剩余 6 条记入 Assumptions「待确认」
- [x] 需求可测且无歧义：FR-001…FR-044 每条含优先级与可观察结果（如「2 秒内发起保存」「切页前先提交当前页」「至少保留 1 页」「二次确认写明页数与图片数」「三档显示宽度」「单篇不超过 100 页」），且 FR 优先级不高于承接它的故事优先级
- [x] 成功标准可度量：SC-001…SC-011 均含量化口径（10 分钟、2 秒、100%、切页 <300ms、p95 <800ms、p95 <1s、2 步、0 变化、0 入口）
- [x] 成功标准技术无关：只描述用户可见结果（「停止输入 2 秒内出现已保存」「切页无可感知卡顿」），不指定实现手段
- [x] 验收场景齐全：4 个用户故事（US1–US3 为 P1、US4 为 P2）共 28 条 Given/When/Then（US1 11 + US2 7 + US3 7 + US4 3），覆盖建谱文、录入保存、多页、配图、字体微调，并为搜索、撤销、离开前保存、三区布局、拖拽排序、改标题/移分类、删分类级联、粘贴清洗、标题校验、切页前保存、图片替换移除补了场景
- [x] 边界情况已识别：14 条 Edge Cases，含超长正文、空页、图片超限、粘贴外部内容、同名谱文、删分类、3 层限制、编目引用、并发覆盖、崩溃丢失、窄屏、图片加载失败、删整篇、数量超预期
- [x] 范围有边界：明确 MUST NOT 项（批量操作 FR-009、离线草稿 FR-020、进阶格式 FR-031、导出/分享/发布 FR-041、模板套用 FR-042、谱书排版 FR-043、后置能力 FR-044），且模板套用以专条声明「不在本期、不留灰色入口」
- [x] 依赖与假设已识别：Assumptions 四张表分别记录与附件 PRD 的 16 条收敛点、5 条与既有 FR-ART-* 的处置、10 项已交付基线、6 条待确认项

## Feature Readiness

- [x] 每条 FR 都有对应验收依据：功能需求按 9 个主题分节，每条都能映射到 US1–US4 的验收场景、Edge Cases 或 Success Criteria 之一；MUST NOT 类 FR 由 SC-011（界面无版式库/模板/批量/导出/分享入口）与范围边界兜底

## Notes

- 本规格由 `/speckit-specify` 产出（2026-11-02），同日经历两轮改动：① `/speckit-clarify` 人工确认 5 条（改标题/移分类、富文本全部后置、删分类级联、自动保存按页提交且状态按整篇汇总、列表全量加载按 ≤200 篇设计）；② 按用户指令「重定范围 把模板套用整体移出本期范围」收缩范围——删除 4 类 8 个版式、套用即重排、版式占位结构、对齐基线、自定义模板，编辑器由四区收敛为三区，图片由「占位框 + 裁剪」改为「正文插图 + 三档宽度」。
- 因此本规格相对初版是**减法**：FR 由 57 条降为 44 条、故事由 5 个降为 4 个；SC 数量由 12 条变为 11 条（删除 3 条版式类，新增 SC-011 承接「界面不留模板入口」）。作废的裁决在 Clarifications 中以删除线保留，便于追溯。
- 仍待确认（留待 `plan`）：① 图片存储形态；② 「类型」取消后既有 FR-ART-1 如何表述；③ 图片/页容量上限是否放宽（默认单张 ≤10MB、单页 ≤6 张、单篇 ≤100 页）；④ 字体清单与字号档位（默认宋/黑/楷 + 3 档）；⑤ 模板套用何时立项；⑥ 页与谱书编目的对应关系。

## 0. 文档概述

### 0.1 背景

参考样本"大谱师 Maker"是一款中文家谱数字编辑软件。其演示明确分出两条性质不同的工作线：

- **谱系线**（视频02）：结构化——录入世系关系与人物生平，实时预览成"世系图 + 信息卡"。
- **谱文线**（视频03）：非结构化叙事——新建序言、传记、家训、名人轶事、封面等**自由文本**，再套用版式模板自动排版、配图、对齐。

本 PRD 仅覆盖**谱文线**。它与谱系线是"编出一本谱"的并列必要组成，但二者数据结构与交互范式不同（一个是关系树，一个是多页富文本文档），因此拆为独立文档，便于分别评审与迭代。本产品**不照搬**样本全部功能，而是提炼真正解决问题的最小集。

### 0.2 设计原则（Linus 哲学 + 最佳实践 + 简洁）

1. **解决真实问题，而非想象中的问题。** 修谱人叙事内容的痛点只有一条：*把序言/传记/家训/封面等文字，按统一、像样的版式排进谱书，并且随手就能看效果*。所有需求以此为标尺。
2. **好品味（Good Taste）。** 套用版式即重排这一机制已能覆盖"排版"，不另建独立排版引擎；多页用"页缩略图"这一种导航机制统一。
3. **默认优于配置。** 样本模板条目下挂"全部/图文/纯文/简介/全图/概览"等冗余过滤维度、新建弹窗出现「主别名/主题名」与「姓氏」并存字段，本质是用配置/冗余掩盖没想清的默认。本产品改为：给一套合理默认版式（4 类），单一标题字段，不暴露冗余过滤。
4. **能不加就不加。** 编辑器内"分享/发布"出口、用户自定义模板深度、在线发布、AI 写作辅助，对"写文→排版→导出"无直接贡献，明确裁剪或后置（见 §11）。
5. **套用即预览（所见即所得）。** 模板套用后文字自动按版式重排，无需单独"预览"环节。
6. **导出是终点。** 谱文最终随谱系一并导出为谱书；谱文编辑器不再设第二处"发布"出口，统一收口到导出门类（见配套谱系 PRD 的 F6）。

### 0.3 范围

- **P0（必须有）**：谱文管理（CRUD + 分类 + 多页）、文本录入、模板套用（核心）、图片插入与调整。
- **P1（应有，首版可简）**：基础富文本（字体/字号）、模板对齐辅助。
- **范围外（本期不做 / 后置 P2）**：用户自定义模板深度、编辑器内分享/发布出口、在线发布、AI 写作辅助、与「谱书」成品排版引擎的深度联动。

## 1. 用户与场景

### 1.1 目标用户

| 角色              | 描述                                    | 依据                       |
| --------------- | ------------------------------------- | ------------------------ |
| **修谱负责人（核心用户）** | 家族/宗亲指定的谱书主编，承担序言/传记/家训/封面等叙事内容的撰写与定稿 | 样本教程定位"新手零基础"；项目含"负责人"字段 |
| **参与录入者（次要）**   | 协助撰写各房各支传记、名人轶事等内容的家族成员               | 样本出现"集体传成""操作日志"多用户痕迹    |

> 与谱系模块用户一致。谱文用户未必懂排版，因此"套用模板即排版"是降低门槛的关键。【待确认】是否需要区分"专业谱师"与"普通家族成员"两类体验。

### 1.2 核心场景

- **S1 建谱文**：通过入口新建一篇谱文，归入某个分类（如"序言""传记""封面"）。
- **S2 写内容**：在画布页打字或粘贴叙事文字（支持多页）。
- **S3 套版式**：从右侧"页面模板库"选版式（标题+正文 / 图文混排 / 全图封面 / 纯文），文字自动按版式重排。
- **S4 配图与对齐**：上传图片到占位框、裁剪缩放，完成图文混排与模板横向对齐。
- **S5 保存成稿**：点击保存，内容可随谱系一并导出为谱书。

## 2. 功能需求

优先级：**P0 必须有**｜**P1 应有（首版可简）**｜**P2 增强（后置）**

### F1 谱文管理 — P0

- **F1.1 新建谱文**：最小字段集——`谱文标题/主题*`（单一字段，合并样本"主别名/主题名"与冗余项）、`所属分类`（默认"默认分类"，可新建）、`地区`（默认"中国"，可选填）。
  - *设计决策*：样本新建弹窗出现「主别名/主题名」与「姓氏」并存，本产品**合并为单一"标题/主题"字段**；「姓氏」属谱系属性，不在每篇谱文重复录入。
  - *依据*：视频03 00:30「创建谱文」弹窗（谱文名称\*/所属分类\*/姓氏/地区/备注）。
- **F1.2** 打开/切换谱文；**F1.3** 删除谱文（二次确认，级联删除其多页内容与图片引用）。
- **F1.4 分类组织**：谱文归入"我的谱文"分类树下，支持新建分类、搜索。
  - *依据*：视频03 右侧分类树结构。
- **F1.5 多页文档**：支持"+添加页"与页缩略图切换（1/2/…）。
  - *依据*：视频03 编辑器最右页缩略图（1/2/+添加页）。

### F2 文本录入 — P0

- **F2.1** 画布页打字或粘贴谱文文字（序言/传记/家训/名人论道/封面等）。
  - *依据*：视频03 00:51 字幕"打字或复制粘贴"。
- *设计决策*：不做复杂块级排版工具栏，文字以段落/标题层级录入即可。

### F3 基础富文本 — P1

- **F3.1** 选中文字可调整字体、字号（最小集）。
  - *依据*：视频03 01:15 字幕"选中文字调字体/字号"。
- *设计决策*：仅保留字体/字号两项；加粗/颜色/对齐等暂归 P2，避免与"模板版式"职责冲突（版式已定义排版基调）。

### F4 模板套用（核心） — P0

- **F4.1** 右侧"页面模板库"提供版式，套用后文字自动按版式重排（所见即所得）。
- **F4.2 版式类型（最小集，4 类）**：`标题+正文`、`图文混排`、`全图/封面`、`纯文`。
  - *依据*：视频03 模板库条目（全文图片版式/介绍版式/标题加正文）、00:60 套用即重排、02:51「名人论道」、03:00 整册封面/内封面、03:42 图文混排。
  - *设计决策*：样本模板条目下挂"全部/图文/纯文/简介/全图/概览"等冗余过滤维度，本产品**收敛为 4 类版式 + 可选变体**，不暴露冗余过滤。
- *设计决策*：模板套用是"重排"而非"覆盖原文"——用户文字内容保留，仅调整版式骨架。

### F5 图片插入与调整 — P0

- **F5.1** 上传本地图片到占位框（封面、图文混排）。
  - *依据*：视频03 01:47–03:42。
- **F5.2** 支持裁剪/缩放，使图片适配版式占位框。
  - *依据*：视频03 图片调整过程。

### F6 模板对齐 — P1

- **F6.1** 提供内容相对模板的横向对齐辅助，套用后一键对齐。
  - *依据*：视频03 02:33–02:39「模板横向对齐完成」。
- *设计决策*：对齐为辅助手段，不要求用户手动逐像素调；模板默认已含合理对齐基线。

> 说明：谱文编辑器的"分享/发布"出口**移除**，统一收口到导出门类（配套谱系 PRD 的 F6），避免两处出口、职责单一。*依据*：设计决策，非样本强制。

## 3. 界面交互

### 3.1 谱文编辑器布局（四区 + 极简顶栏）

```
┌──────────┬──────────────────┬──────────────┬──────────────┐
│ 左：我的谱文 │ 中：文档画布(多页) │ 右：页面模板库 │ 最右：页缩略图 │
│ 分类树/搜索  │ 空白页→录入→套版式 │ 4类版式+变体   │ 1/2/+添加页   │
└──────────┴──────────────────┴──────────────┴──────────────┘
       顶部(极简)：保存 | (分享/发布收口至导出，不在此出现)
```

- *依据*：视频03 编辑器（左侧文件树、中部画布、右侧模板库、最右多页缩略图）。

### 3.2 关键交互

- **套用模板**：右侧模板库选版式 → 画布文字自动重排。*依据*：视频03 00:60、02:51。
- **配图**：上传本地图 → 占位框 → 裁剪/缩放 → 图文混排。*依据*：视频03 01:47–03:42。
- **多页**：页缩略图切换与"+添加页"。*依据*：视频03 多页缩略图。
- **新建入口**：控制台 / 项目总览 / 谱文模块三种入口均可新建。*依据*：视频03 开头多入口。

## 4. 数据需求

### 4.1 实体与关系（谱文域最小模型）

- **Article（谱文）**：id、谱系id（所属家谱项目）、标题/主题、所属分类、地区、版式类型（当前页/默认）、多页内容（每页：富文本片段 + 图片引用列表）、创建/修改时间。
- **Template（版式模板）**：id、类别（`标题+正文` / `图文混排` / `全图封面` / `纯文`）、缩略图、占位结构（标题位、正文位、图片位、对齐基线）。
- **Page（谱文页）**：id、articleId、版式引用、正文内容、图片引用、顺序。
- 关系：谱文 → 分类（多对一）；谱文 → 模板（套用，按页或整篇）。

### 4.2 字段约束

- 谱文标题必填；所属分类默认"默认分类"；地区默认"中国"；页码顺序自增。

### 4.3 数据归属与便携

- 谱文数据应可随谱系一并本地保存/导出，用户拥有完整所有权（Linus：数据不锁死在厂商）。*【待确认】存储形态（本地文件 / 云端账户）。*

## 5. 权限角色（最小集，与谱系模块一致）

| 角色      | 权限         | 说明        |
| ------- | ---------- | --------- |
| **所有者** | 全部         | 修谱负责人     |

- *设计决策*：仅 3 角色，不做字段级细粒度权限。*【待确认】是否需账户体系支撑多角色。*

| 场景            | 处理策略                  | 依据 / 说明                     |

## 7. 非功能需求

- **N1 实时性**：模板套用后文字重排延迟 < 200ms。
- **N2 性能**：单篇谱文数十页、含数十张图片时排版/保存无明显卡顿。
- **N3 易用性**：零基础用户无需培训，10 分钟内完成"建谱文→套版式→保存"。
- **N4 可移植/所有权**：谱文随谱系导出，格式开放，数据可脱离本产品长期保存。
- **N5 可靠性**：编辑过程本地自动存盘，异常退出不丢数据。

## 8. 验收标准

- **AC-F1**：新建谱文填标题+分类可创建并进入编辑器；标题为空被拦截；可新建分类、删除谱文（二次确认）。
- **AC-F2**：可在画布页打字/粘贴文字；可"+添加页"并在页缩略图间切换。
- **AC-F3（套版式）**：套用"标题+正文"模板后，文字按版式自动重排；切换"图文混排/全图封面/纯文"均生效。
- **AC-F4（图片）**：上传本地图片可进入占位框并裁剪缩放，参与图文混排且不溢出。
- **AC-F5（对齐）**：套用后可用模板对齐辅助使内容横向对齐。
- **AC-集成**：谱文可随谱系一并导出，内容与录入/套版一致（见配套谱系 PRD 的 F6 验收）。
- **AC-N**：数十页 + 数十图时，套用重排与保存达到 N1/N2 指标（阈值【待确认】）。

## 10. 设计决策记录（本产品 vs 参考样本）

| 参考样本功能                    | 本产品决策                  | 理由（Linus / 简洁）  |
| ------------------------- | ---------------------- | --------------- |
| 新建弹窗「主别名/主题名」+「姓氏」并存      | 合并为单一标题/主题字段           | 冗余录入；姓氏属谱系属性    |
| 模板下挂"全部/图文/纯文/简介/全图/概览"过滤 | 收敛为 4 类版式 + 可选变体       | 冗余过滤维度          |
| 模板套用 = 覆盖原文？              | 套用 = 保留文字、仅重排版式骨架      | 不丢失用户内容         |
| 谱文编辑器内「分享/发布」出口           | 移除，收口至导出模块             | 避免两处出口、职责单一     |
| 复杂富文本工具栏（加粗/颜色/对齐）        | 仅字体/字号两项（P1）           | 版式已定排版基调，避免职责冲突 |
| 模板对齐                      | 辅助手段，模板默认含合理对齐基线       | 不要求用户逐像素调       |
| 实时预览                      | **强化**为"套用即重排"，无独立预览开关 | 样本验证的核心价值       |

## 11. 已裁剪需求清单（明确不做 / 后置）

- **裁剪（本期不做）**：谱文编辑器内分享/发布出口、冗余模板过滤维度、复杂富文本工具栏（加粗/颜色/对齐等）。
- **后置（P2）**：用户自定义模板、在线发布、AI 写作辅助、与「谱书」成品排版引擎的深度联动、万页级性能优化。

> 裁剪原则：凡不直接服务于"写文 → 套版式 → 配图对齐 → 导出"主线的，一律后置或删除；确需时再以最小成本补回。

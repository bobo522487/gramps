# 架构决策记录（ADR）

> **回答什么问题**：定了哪些代价高或难回头的决策、为什么选 A 不选 B、接受什么代价、出现什么信号该重估。
> **读者**：技术负责人 · 新人 · AI Agent　**长度上限**：3 页
> **不写什么**：实现现状与模块划分（`docs/architecture.md`）、接口契约（`docs/interfaces.md`、`docs/contracts/`）、可度量阈值（`docs/nfr.md`）、编排与进度（`docs/roadmap.md`）、不可协商的原则（`.specify/memory/constitution.md`）、术语（`docs/glossary.md`）、表与列（`docs/data-model.md`）。

ADR 记的是**理由**，不是现状。「我们用了 A」写在架构与接口文档；「为什么是 A 而不是 B、为此长期承担什么」只写在这里。同一份结论不在两处各写一遍。

## 1. 规则

| 规则 | 内容 | 执行者 |
| --- | --- | --- |
| 唯一编号 | `NNNN` 四位递增，不复用、不重排。`0014` / `0015` 从未创建，保持空号，不补号 | 新增时取当前最大号 +1 |
| 已发布不回改 | 决策结论变了就新增一条，在旧条标 `superseded by NNNN`；旧条不改结论、不改编号 | PR 评审 |
| 事实陈述必须与现状一致 | 与「决策结论」不同：「当时没做 / 仍是 `in_progress` / 待复核」这类**对现状的描述**过期了就直接改，不必新增 ADR，也不留两个版本 | PR 评审；已被推翻的措辞由 `pnpm test` 拦（`tests/s8-stage-e.test.ts`） |
| 只记为什么 | 背景、选项、理由、代价、重估触发。「我们用了 A」不进 ADR | PR 评审 |
| 未决策不登记 | 没有执行者的一行结论不算决策，不进 §3 索引 | 索引维护者 |

**编号只有一套。** 旧体系曾同时用清单序号、文件号、待决序号三套编号指同一批决策，其中一条清单结论还被判过「无文件、无执行者，视为未决策」。本目录只认 `NNNN`：那一类一行结论的现状归位到架构、接口与阈值文档，不在这里另立第二份清单。

## 2. 什么时候必须写

- 技术栈、框架、存储或编辑器选型。
- 跨模块边界、隔离模型、接口契约形态的确定。
- 偏离 `.specify/memory/constitution.md` 任一原则的例外。
- 不可逆的数据迁移、租户边界变更与兼容性取舍。
- 变更文档交付约定，或引入对外 API。

**单向门**（改起来要数据迁移或全量重排）必须写；**双向门**（错了能改）不必留档，除非代价要长期承担。写完在 §3 登记一行——只写文件不登记，按「约束要有执行者」视为未决策。流程见 `CONTRIBUTING.md` 的变更对照表与 PR 自查。

本目录**只存索引，不存正文**：背景、选项对比、代价与「何时重估」写进当次提交信息与 PR 描述。理由见 §3 末尾。

## 5. 新增一条决策

三步，不建文件：

1. 在 §3 追加一行：编号（当前最大号 +1）、结论式一句话、`accepted`、原始决策日、单向门 / 双向门、为什么值得单独留档。
2. 结论变了不改旧行：新增一行，旧行在 §4 标 `superseded by NNNN`。
3. 把背景、考虑过的选项、代价与「何时重新评估」写进提交信息，并用 `ADR NNNN` 作标题前缀，保证 `git log --grep` 能拉出来。

> 关联行用 `S<n>` 而不是旧骨架里的 `R#`：`R` 前缀已被风险登记占用，`roadmap.md` 的条目 ID 是 `S1`–`S7`。

## 6. 核对

```bash
# 已登记的编号没有重复（无输出即通过）
grep -oE '^\| `[0-9]{4}`' docs/adr/README.md | sort | uniq -d

# 本目录只应有本 README，不应出现决策正文文件（无输出即通过）
find docs/adr -maxdepth 1 -type f ! -name README.md

# 一条决策能否拉通到代码与测试
grep -rn '0020' docs/ tests/ lib/db/migrations/
```

编号唯一性与「不存正文」靠 PR 评审加上面第一条命令；「退役语义不得回到文档描述里」由 `pnpm test` 的静态断言守住（`tests/s8-stage-e.test.ts`）。

写在文档里但拦不住的规则等于没有规则：本文件唯一可机检的部分是 §3 编号唯一性与退役语义黑名单，其余（「只记为什么」「未决策不登记」）靠评审。

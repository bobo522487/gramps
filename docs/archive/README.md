## 2. 引用规则

- **活跃文档可以引用归档材料作为证据**（如 ADR 的评审出处），链接必须指向本目录下的真实文件。
- **归档材料不更新**：其中的路径、行号、表数量、Action 名按当时状态写，已知结构性失效（例如指向已删除的 `lib/db/schema.ts` 行号）。这些死链**不修**。
- **归档材料不参与 `docs:check`**：扫描范围排除本目录，理由见 [README §5](../README.md)。归档内的相对链接可能失效，不作为提交阻断项。
- 需要长期有效的结论，必须提炼进 `architecture/` 或 `decisions/`，不能只留在归档里。

## 3. 执行计划的 checkbox 不代表进度

`plans/` 里的计划使用 `- [ ]` 模板，**11 份计划中未勾选数远多于勾选数，但落地物（代码、迁移、文档）证明其中 10 份已执行完**。判断"做到哪一步"只看 [11-需求与实现状态](../architecture/11-需求与实现状态.md)，不看计划里的复选框。
